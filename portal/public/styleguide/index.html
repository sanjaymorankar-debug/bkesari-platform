Kesari 1.0.0

The one design system behind bkesari.com, LadWani, Education and TaskList. Every component below is shown in its states: default, hover, focus, disabled, loading, error and empty. This page exists on dev and test only.

Load it with <link rel="stylesheet" href="/kesari-ui/1.1.0/kesari.css"> and <script src="/kesari-ui/1.1.0/kesari.js"></script> in <head>; set data-project on <html> for the accent. Source: packages/kesari-ui. Spec: docs/design/design-system.md.
